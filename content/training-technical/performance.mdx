This topic page is a learning checklist for developers focusing on **performance**.

## Learning checklist

- Measure a slow action before rewriting it
- Search domains, prefetch, and N+1 style record access
- Indexes on fields you actually filter
- What belongs in a scheduled action versus a user click
- How to tell a data-volume problem from a code problem

## Practice

Take one list view that feels slow, note the domain and the fields it loads, and name one change you would try first.
