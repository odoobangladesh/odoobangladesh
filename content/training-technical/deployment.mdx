This topic page is a learning checklist for developers focusing on **deployment**.

## Learning checklist

- Separate development, staging, and production
- Addon paths, dependencies, and a repeatable install
- Database backups before every upgrade
- What a release includes: code, data files, and a rollback
- How deployment lines up with the go-live checklist

## Practice

Write the steps to move one custom addon from a staging database to production, including the backup you take first.
