This topic page is a learning checklist for developers focusing on **OWL**.

## Learning checklist

- Components, templates, and props
- State, hooks, and when to re-render
- How an OWL component is registered in a module
- When an XML form view is enough and a custom component is not
- How to keep a component testable

## Practice

Build a small component that reads a record and shows one computed value, then mount it from a module instead of a standalone page.
